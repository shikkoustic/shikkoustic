### Featured Projects

#### 🏏 [CricLens](https://github.com/shikkoustic/CricLens) — Cricket Batting Analysis from Video
`PyTorch` `ViTPose` `YOLO11` `FastAPI` `OpenCV`
- End-to-end pipeline for shot classification and technique scoring: YOLO11 + ByteTrack tracking, gradient-boosted striker identification, and ViTPose 2D pose extraction.
- Trained an LSTM shot classifier (0.785 macro-F1, 8 classes) and a VAE technique scorer (Spearman 0.603).
- Served through a FastAPI web app with pose overlays and LLM coaching feedback.

#### 🧮 [BaseCase](https://basecase-red.vercel.app) — Curated DSA Practice Platform
`Next.js` `TypeScript` `PostgreSQL (Supabase)` `Drizzle`
- A free, curated DSA question bank (600+ unique problems across 26 topics) built for interview prep, verified problem-by-problem against LeetCode's live API — not a copy of any single reference sheet.
- Tracks LeetCode and CodeChef progress with a personal dashboard, topic-wise roadmap, and contest tracker.
- Deployed in production on Vercel with a Supabase Postgres backend.

#### 📚 [Examen](https://github.com/shikkoustic/Examen) — RAG-Powered Study & Research Assistant
`FastAPI` `LangGraph` `RAG` `ChromaDB` `MCP`
- A Study Agent that parses uploaded PDFs into a structure-aware outline and teaches section-by-section, plus a multi-agent Research Agent that generates cited, downloadable reports.
- RAG pipeline (ChromaDB, sentence-transformer embeddings, cross-encoder reranking) with a web-augmented fallback.
- Integrated MCP tool servers for notes, quiz generation, and live YouTube search.

#### 🌫️ [Vayu — AQI Forecasting](https://github.com/shikkoustic/Vayu-AQI-Forecasting) — Satellite & Weather Data
`Python` `Scikit-Learn` `NumPy` `HTML/CSS/JS`
- ML models (CatBoost, LightGBM, XGBoost, Random Forest) forecasting AQI using satellite data from Google Earth Engine and meteorological parameters.
- Feature engineering, hyperparameter tuning, and experiments with TabPFN, GRU, and LSTM.
- Built an end-to-end pipeline from data collection to visualization.
